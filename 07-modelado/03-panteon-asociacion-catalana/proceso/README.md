# Registro del proceso

1. `01_nube_densa_alineada.png`: nube importada y alineación inicial.
2. `02_volumenes_principales.png`: planta retranqueada, cubiertas, linterna y anexo.
3. `03_superposicion_nube_modelo.png`: comparación visual con geometría en alambre.
4. `04_detalles_esquematicos_antes_refinado.png`: estado previo al refinado de ornamentos.
5. `05_ornamentos_refinados.png`: incorporación de follaje, volutas, medallón e inscripción.
6. `06_detalle_ornamentos_fachada.png`: inspección cercana de los detalles.
7. `07_modelo_final_blender.png`: vista final de conjunto.

Son capturas reales de la interfaz de Blender tomadas durante la sesión. Las etapas 4–5 son intermedias; el modelo final incorpora la corrección de la escalinata y de superficies coincidentes. Ver README principal para separar geometría referenciada de detalles interpretados.
